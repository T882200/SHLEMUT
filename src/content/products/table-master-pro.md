## TableMaster Pro — InDesign Table Automation

Stop wasting hours manually formatting tables. TableMaster Pro automates the entire process — from importing data to applying consistent, beautiful formatting across your entire document.

### What It Does

1. **Import from CSV/Excel** — Drag and drop your data files
2. **Auto-format** — Apply pre-built or custom table styles in one click
3. **Batch processing** — Format all tables in a document simultaneously
4. **Smart headers** — Automatic repeating headers across pages
5. **Alternating rows** — Configurable zebra-stripe patterns

### Features

- One-click table generation from external data
- 12 built-in professional table styles
- Custom style builder with live preview
- Batch format all tables in a document
- RTL table support for Hebrew/Arabic layouts
- Automatic cell padding optimization
- Works with threaded text frames

### System Requirements

- Adobe InDesign CC 2020 or later
- macOS 10.15+ or Windows 10+
- 4GB RAM minimum

### Installation

1. Purchase and receive your serial key via email
2. Download the `.jsx` script file
3. Place in your InDesign Scripts folder
4. Enter your serial key on first launch
