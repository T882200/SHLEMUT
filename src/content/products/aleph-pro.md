## Aleph Pro — Modern Hebrew-Latin Typeface

Aleph Pro is a carefully crafted typeface that bridges Hebrew and Latin scripts with consistent visual harmony. Designed for the modern era, it features clean geometric forms while retaining the warmth and readability essential for extended text.

### Key Features

- **Full Hebrew & Latin support** — Designed from the ground up for both scripts
- **5 weights** — From Light (300) to Bold (700)
- **Variable font included** — Smooth weight interpolation
- **600+ glyphs** — Comprehensive character set
- **OpenType features** — Ligatures, stylistic alternates, and more

### Use Cases

- Editorial design and magazines
- Brand identity systems
- Web and app interfaces
- Book typography
- Packaging and signage

### What's Included

- `.otf` files for all 5 weights
- `.ttf` files for web use
- Variable font file (`.woff2`)
- Specimen PDF
